# DesignPatternUMC - ModuloAcademico

## Descrição
ModuloAcademico é um sistema de gestão desenvolvido para uma instituição acadêmica, com funcionalidades para administrar uma biblioteca e a secretaria da instituição. O sistema permite realizar operações de CRUD (Create, Read, Update, Delete) para gerenciar livros e alunos, armazenando as informações em um banco de dados MySQL.

## Funcionalidades
### Biblioteca
- Inserir novo livro
- Atualizar informações de um livro
- Remover um livro
- Consultar informações de um livro

### Secretaria
- Inserir novo aluno
- Atualizar informações de um aluno
- Remover um aluno
- Consultar informações de um aluno

## Tecnologias Utilizadas
- C#
- MySQL
- MySql.Data.MySqlClient

## Requisitos
- .NET Framework ou .NET Core
- MySQL Server
